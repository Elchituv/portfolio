# AI Builder

Projects that use AI to automate real work: workflow automation, LLM-powered data extraction and classification, and agents that are measured, not just demoed.

**Focus areas**
- **Workflow automation** with n8n, Make and Zapier — e.g. AI-assisted CRM data entry and enrichment
- **LLM pipelines** in Python — extracting, classifying and summarising unstructured text into clean tables
- **Agents with evaluation** — labelled test sets, tracing and regression checks, so quality is tracked with numbers
