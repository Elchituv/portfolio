# הפרויקט כיחידת לימוד

הפרויקט בנוי כך שאפשר ללמד אותו כמו שהוא. הנתונים כוללים בכוונה בעיות איכות אמיתיות, ולכל שלב יש מספר יעד שהלומד יכול לבדוק את עצמו מולו.

| קובץ | למי | מה יש בו |
|---|---|---|
| [`lesson_plan.md`](lesson_plan.md) | מדריך | שיעור לדוגמה של 15 דקות: "לקוחות רפאים", ניקוי נתונים ב-Power Query |
| [`exercise.md`](exercise.md) | לומד | דף תרגיל עם משימות ומספרי יעד |
| [`answer_key.md`](answer_key.md) | מדריך | פתרון מלא, צעדי Power Query וכלי הערכה |
| [`../sql/control_numbers.sql`](../sql/control_numbers.sql) | מדריך | חישוב עצמאי של כל מספרי היעד |
| [`../data_generator/generate_data.py`](../data_generator/generate_data.py) | מדריך | גרסה חדשה של התרגיל לכל מחזור: `python generate_data.py out 12345` |

**איך עובדים עם גרסה חדשה:** מריצים את המחולל עם seed אחר, ואז את `control_numbers.sql` על הקבצים החדשים. כך מתקבלים מספרי יעד חדשים, וכל מחזור לומדים מקבל תרגיל משלו.

**הערה:** כל הטעויות שמופיעות ב"טעויות נפוצות" בתוך מערך השיעור קרו בפועל בזמן שבניתי את הפרויקט. לכן הן אמינות.
