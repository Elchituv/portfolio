# תרגיל: לנקות את ה-ERP של PharmaDist

**רקע:** PharmaDist היא חברה בדיונית שמפיצה תרופות לבתי חולים, לקופות חולים ולבתי מרקחת. קיבלתם ממערכת ה-ERP שלה ארבעה קבצים. לפני שבונים דוח כלשהו, צריך לוודא שאפשר לסמוך על הנתונים.

## משימות
1. **טעינה:** טענו את ארבעת הקבצים מהתיקייה `data/`. בחלון שנפתח לחצו על **Transform Data**, ולא על Load.
2. **פרופיילינג:** בלשונית View הפעילו את Column quality, Column distribution ו-Column profile. בשורת הסטטוס בתחתית בחרו **entire data set**.
3. **איתור:** מצאו **6 בעיות** ורשמו אותן בטבלה:

| קובץ | עמודה | מה הבעיה | כמה שורות |
|---|---|---|---|
| | | | |

4. **תיקון:** תקנו כל בעיה ב-Power Query. כל תיקון צריך להופיע כצעד ברשימה Applied Steps.
5. **מיזוג:** מזגו את `Orders` לתוך `OrderLines` לפי OrderID (Left Outer), ושנו את שם השאילתה ל-`FACT_Sales`.
6. **עמודה מחושבת:** הוסיפו עמודה בשם `NetAmount` עם הנוסחה `[QtyDelivered] * [UnitPrice] * (1 - [DiscountPct])`, מסוג Decimal Number.
7. **בדיקה:** השוו את התוצאות שלכם למספרי היעד:

| בדיקה | יעד |
|---|---|
| מספר השורות ב-FACT_Sales | 72,890 |
| מספר הערכים השונים של CustomerID ב-Orders | 140 |
| מספר הערכים השונים של Region | 5 |
| מספר המוצרים בלי קטגוריה | 0 |
| סך NetAmount (בוויזואל Table) | 180,066,172 |
